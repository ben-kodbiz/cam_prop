About Open Evidence

Open Evidence is an open-source project documenting contested claims, international-law records and corporate relationships. It is built to be a transparent evidence machine that makes propaganda harder to sustain — regardless of who produces it.

Core principles:

  • Evidence first.
  • Attribution always.
  • Uncertainty explicitly stated.
  • No predetermined conclusions about any side of any conflict.
  • Human approval before publishing high-impact findings.
  • Corrections are tracked; history is never silently rewritten.

The project code is licensed under AGPL-3.0. Where legally appropriate, project-created data is published under CC BY 4.0. Third-party copyrighted material is only referenced (short excerpts, links, metadata), never mirrored.
